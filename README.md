# Apple Store

Proyecto desarrollado para Talento Tech utilizando HTML, CSS y JavaScript.

## Descripción

Apple Store es una tienda web inspirada en la página oficial de Apple.

La aplicación consume una API pública para obtener información de productos y permite al usuario interactuar con un carrito de compras persistente.

## Funcionalidades

- Diseño responsive
- Navegación interna
- Hero Section
- Productos generados dinámicamente
- Consumo de API mediante Fetch
- JavaScript ES6
- Carrito de compras
- Aumentar y disminuir cantidades
- Eliminar productos del carrito
- Persistencia con LocalStorage
- Buscador de productos
- Formulario de contacto mediante Formspree
- Video integrado
- Bootstrap Offcanvas
- Font Awesome

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript (ES6)
- Bootstrap 5
- Fetch API
- LocalStorage
- Flexbox
- CSS Grid
- Media Queries
- Font Awesome
- Formspree
- DummyJSON API
