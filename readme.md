# Apple Store

Proyecto realizado para Talento Tech.

## Descripción

Landing page inspirada en Apple desarrollada con HTML5 y CSS3.

El sitio cuenta con:

- Diseño responsive
- Flexbox
- CSS Grid
- Navegación interna
- Hero section
- Cards de productos
- Formulario de contacto
- Multimedia integrada

## Tecnologías utilizadas

- HTML5
- CSS3
- Flexbox
- Grid
- Media Queries
- Font Awesome
